# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately through GitHub's [private vulnerability reporting](https://github.com/muneebulhassanpak/nextjs-neon-project-management-saas/security/advisories/new). Include steps to reproduce and the impact you expect.

You'll get a reply within 3 working days. Once a fix is released, the report is credited in the changelog unless you'd rather stay anonymous.

## Supported versions

Only the latest release on `main` receives security fixes.
